# /scripts

Вспомогательная автоматизация: обновление `ai/DASHBOARD.md` по данным CI
(сборка, тесты, число открытых багов), проверка целостности документации
(например, что на каждый TASK-ID из `templates/task.md` есть Handoff-запись).
Необязательный, но рекомендуемый слой — особенно при команде из 5+ ролей/ИИ.
