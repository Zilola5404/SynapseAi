# Definition of Done — Критерии завершения

> Обновляет: Project Manager совместно с Chief Architect.
> Когда обновляется: при смене процесса или после ретроспективы, где выявлен пробел.
> Используют: все роли, обязательная сверка перед каждым Handoff.
> Обязателен: да.

## Задача считается завершённой, когда:
- [ ] Реализован весь функционал согласно `templates/task.md`
- [ ] Пройдена самопроверка исполнителем (`PROJECT_RULES.md`, статья 2)
- [ ] Код собирается без ошибок
- [ ] Написаны/обновлены тесты для изменённого функционала
- [ ] Все тесты проходят
- [ ] Пройден Code Review (`templates/code_review.md`) без открытых замечаний
- [ ] Обновлена связанная документация (если функционал влияет на `AI_CONTEXT.md` или `/specifications`)
- [ ] Commit-сообщение соответствует `GIT_WORKFLOW.md`
- [ ] `CURRENT_STATUS.md` обновлён

## Этап считается завершённым, когда:
- [ ] Все задачи этапа закрыты по критериям выше
- [ ] Пройден Independent Audit (`templates/audit.md`)
- [ ] Пройден QA (`templates/qa_report.md`) без критических и блокирующих багов
- [ ] Обновлён `/ai/DASHBOARD.md`
- [ ] Технический долг, возникший на этапе, зафиксирован в `templates/technical_debt.md`

## MVP считается завершённым, когда:
- [ ] Реализованы все функции, отмеченные как MVP-scope в `AI_CONTEXT.md`
- [ ] Пройдено сквозное end-to-end тестирование основных пользовательских сценариев
- [ ] Нет открытых критических и блокирующих багов
- [ ] Проведён Security Report по базовым угрозам (`templates/security_report.md`)
- [ ] Продукт можно продемонстрировать реальному пользователю без сопровождения разработчика

## Продукт считается готовым к Production, когда:
- [ ] Выполнены все критерии MVP
- [ ] Пройден Performance Report с приемлемыми показателями нагрузки (`templates/performance_report.md`)
- [ ] Настроены мониторинг, логирование, алертинг
- [ ] Есть план отката (Rollback) — см. `GIT_WORKFLOW.md`
- [ ] Пройден финальный Independent Audit всей системы
- [ ] Release Manager подтвердил готовность релиза (`templates/release.md`)
- [ ] Owner дал явное подтверждение (Owner Approval)
