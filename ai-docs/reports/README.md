# /reports

Здесь хранятся заполненные отчёты — фактическая история проекта: аудиты,
code review, QA-отчёты, security/performance-отчёты, риски, технический долг.

Правила именования: `<тип>_<TASK-ID или дата>.md`, например
`code_review_TASK-042.md`, `audit_2026-08-06.md`.

Записи никогда не удаляются и не переписываются задним числом — только
архивируются согласно `/docs/DOCUMENTATION_LIFECYCLE.md`.
